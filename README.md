# SAINTSONGO
This is a real-time bus tracking mobile app for St. George’s School buses.  
It allows parents to see live bus locations so they can anticipate when their sons are arriving and be ready for pickup on time.

The app is built using React Native and Firebase, with real-time GPS hardware integration.

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- Expo Go (Mobile App)
- Firebase Account
- Npm or yarn

### Installing
  1. bash
  2. git clone https://github.com/ShayJah/SaintsOnGo

### Deployment
- npx expo start

## Built With
React Native - Mobile application developement
Firebase - Backend services and real time developement
